sequenceDiagram participant Client participant API as API Route participant SEL as Selection Service participant AI as AI Service participant REG as Node Registry participant CACHE as Performance Cache Client->>API: POST /api/nodes {action: "select-for-goal", goal, context} API->>SEL: selectNodesForGoal(goal, context) SEL->>AI: analyzeGoal(goal, context) AI-->>SEL: {category, tags, complexity, performance} SEL->>REG: searchNodes(criteria) REG->>CACHE: Get performance metrics CACHE-->>REG: Metrics data REG-->>SEL: Candidate nodes SEL->>AI: rankAndSelectNodes(candidates, goal) AI-->>SEL: Ranked node IDs SEL->>REG: getNode(nodeId) for each REG-->>SEL: Node definitions SEL-->>API: Selected nodes API-->>Client: Node selection result
